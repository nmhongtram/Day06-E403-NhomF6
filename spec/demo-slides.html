Four Paths (theo Spec)
Demo cover đủ 4 scenario của spec
✅
Happy Path
User cung cấp đủ thông tin → AI search → Hiển thị hotels → Chọn phòng → Xác nhận → Booking thành công
"Tôi muốn đi Phú Quốc cuối tuần này 2 người"
→ Destinations → Hotels → Rooms → Confirm → VNP-2026-XXXX ✓
show_hotels → show_rooms → save_booking
❓
Low-confidence Path
Thông tin không đủ → AI hỏi một câu cụ thể → User trả lời → Tiếp tục flow
"Muốn đổi booking" (thiếu mã booking)
→ "Bạn muốn đổi booking nào? Mã VNP-...?"
→ User cung cấp → xử lý tiếp
ask_clarification + quick replies
❌
Failure Path
Booking không tìm thấy hoặc policy không có trong dữ liệu → LLM trả lời đồng cảm + gợi ý CSKH
"Hủy VNP-9999-8888" (không tồn tại)
→ FailureWidget: 📞 1800 1234 | 💬 Chat nhân viên | 🔗 Chính sách
show_failure + CSKH escalation
🔄
Correction Path
User sửa thông tin → AI merge với entities cũ + re-search → Xác nhận cập nhật
"Tìm 2 người" → kết quả → "Không phải 2, là 4 người gia đình"
→ "Đã cập nhật! Kết quả mới ưu tiên Kids Club 🏖"
correction intent + previous_entities merge
